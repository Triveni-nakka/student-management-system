# Student Management System

A Java Full Stack web application for managing student records.

## Technologies
- Java 17
- Spring Boot
- Spring Data JPA / Hibernate
- MySQL
- HTML, CSS, JavaScript
- Maven

## Features
- Add student
- View students
- Search by name
- Update student
- Delete student
- MySQL persistence

## Run
1. Install JDK 17, MySQL and Maven.
2. Create/import the project as a Maven project.
3. Open `src/main/resources/application.properties`.
4. Replace `YOUR_MYSQL_PASSWORD` with your MySQL password.
5. Run `StudentManagementApplication`.
6. Open `http://localhost:8080`.
